# فاتورة الدفع (InvoicePay) 📱🧾

تطبيق أندرويد متكامل لإدارة ومتابعة فواتير الدفع، مع ميزة **تعديل الفاتورة حتى بعد إتمامها**، وحفظ التعديلات وإعادة احتساب المبالغ تلقائياً.

تم تطوير التطبيق بالكامل باستخدام **Kotlin** و **Jetpack Compose** و **Room Database** وفق معايير **Material Design 3** مع دعم كامل للغة العربية (RTL).

---

## 🌟 الميزات الرئيسية

1. **تعديل الفاتورة بعد إتمامها:**
   - إمكانية فتح أي فاتورة مكتملة أو مدفوعة وتعديل جميع تفاصيلها بحرية تامة.
   - تعديل بيانات العميل، رقم الفاتورة، تاريخ الاستحقاق، وطريقة الدفع.
   - تعديل البنود: الاسم، الكمية، سعر الوحدة، والوصف.
   - إعادة احتساب المجموع الفرعي، الخصم، ضريبة القيمة المضافة (15% VAT)، الإجمالي، والمدفوع والمتبقي تلقائياً.
   - حفظ التعديلات في قاعدة البيانات Room وتحديث تاريخ آخر تعديل مع وسم الفاتورة كـ *(مُعدّلة بعد الإتمام)*.

2. **عرض تفصيلي للفاتورة:**
   - بطاقة متكاملة تعرض حالة الفاتورة (مكتملة، قيد الانتظار، مدفوعة جزئياً).
   - جدول البنود وتفاصيل الحساب المالي الكامل.
   - إمكانية مشاركة الفاتورة كنص منسق عبر تطبيقات المراسلة.
   - تبديل حالة السداد مباشرة (تعيين كمكتملة أو قيد الانتظار).

3. **لوحة تحكم وإحصائيات مالية:**
   - إجمالي المبالغ المحصلة (الفواتير المكتملة).
   - إجمالي المبالغ المتبقية قيد السداد.
   - تصفية سريعة حسب الحالة: الكل، مكتملة، قيد الانتظار، مدفوعة جزئياً.
   - بحث فوري برقم الفاتورة، اسم العميل، أو البند.

## 📦 التثبيت والتشغيل
- ملف الـ APK الجاهز للتثبيت المباشر على الهاتف موجود باسم: `quick_invoice.apk`.
- لفتح المشروع في **Android Studio**، قم بفتح هذا المجلد مباشرة واستخدم Gradle للمزامنة والتشغيل.
