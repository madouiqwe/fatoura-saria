## المميزات

- **حزم بسعات مختلفة لكل منتج**: كل سلعة لها حقل «عدد القطع في الحزمة» مستقل (10، 12، 24 ...).
- **بيع بالحبة أو بالحزمة**: تبديل فوري لوحدة البيع داخل بند الفاتورة، مع حساب عدد القطع تلقائياً.
- **حسابات دقيقة**: سعر الحزمة = سعر الحبة × سعة الحزمة، والإجمالي يُحدَّث لحظياً.
- **فاتورة عصرية**: ترويسة متدرجة اللون بشعار المؤسسة ورقم الفاتورة وحالة الدفع، بطاقات بيانات للعميل وطريقة الدفع، جدول أصناف مخطط، شريط إجمالي بارز، وتذييل المؤسسة (نفس التصميم على الشاشة وفي PDF).
- **طباعة وحفظ PDF**: عبر نظام أندرويد (PrintManager) مع دعم كامل للعربية وتشكيل الحروف.
- **مشاركة PDF**: إرسال الفاتورة مباشرة عبر التطبيقات.
- **دليل السلع**: إضافة، تعديل، حذف، بحث، فئات، وباركود.
- **الفواتير المحفوظة**: بحث وتصنيف حسب الحالة، مع شريط سفلي في شاشة الفاتورة يحمل زرّي «تعديل الفاتورة» و«حذف» بعد الانتهاء. تعديل الكمية أو السعر في فاتورة حاسبة يحدّث نص العملية نفسه (`250 × 10` ← `250 × 12`) في الشاشة والملف والإيصال.
- **الوضع السريع**: اضغط «حبة» أو «حزمة» لإضافة السلع إلى سلة، عدّل الكميات، ثم احفظ فاتورة نقدية فوراً. وتضم الشاشة حاسبة لتحويل أي مبلغ إلى فاتورة.
- **حاسبة فورية (v2.3)**: شاشة ثابتة بلا تمرير مع لوحة أرقام ظاهرة دائماً، تعبيرات متسلسلة بأولوية الضرب والقسمة (`350 + 200 × 12`)، وتعديل كامل لكل بند (الكمية + سعر الحبة + الإجمالي) مع تحديث فوري لسطر الفاتورة المطبوع، ومنع القسمة على صفر، وضرب سريع لمضاعفات الحبات (6، 10، 12، 24، 50، 100).
- **طباعة حرارية مباشرة XP-P801**: إيصال 80mm عبر البلوتوث بترويسة في الوسط، فواصل منقّطة وأعمدة بيان/مبلغ بخطوط دلالة، بنود مرقّمة، وشريط إجمالي معكوس عالي التباين، مع تجهيز تلقائي للورق وقص.
- **إعدادات المؤسسة**: الاسم، الهاتف، العنوان، وعبارة تذييل الفاتورة.
- **تخزين محلي**: كل البيانات في ملف JSON داخل التطبيق (بدون إنترنت أو حساب).

## البناء

```bash
# يتطلب JDK 17 و Android SDK 36
./gradlew assembleDebug
```

ملف APK الناتج:

```
app/build/outputs/apk/debug/app-debug.apk
```

## البنية

```
app/src/main/java/com/madoui/fatoura/
├── data/          # النماذج + التخزين المحلي (JSON)
├── print/         # توليد PDF والطباعة والمشاركة
├── ui/            # الشاشات، المكوّنات، الثيم، التنقل
└── util/          # تنسيق الأرقام والتواريخ
```
